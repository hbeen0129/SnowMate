# SnowMate 🏂❄️

> Apple Watch와 CoreLocation, HealthKit을 활용해 스노보드를 즐기는 사람들의 라이딩 데이터를 시각화하는 귀여운 스노보드 트래킹 앱 🏂✨

---

## 🌟 앱 소개

SnowMate와 함께라면:

- ⛰️ **고도 & 속도 트래킹** — 실시간 내 고도 변화와 속도 확인
- 📅 **캘린더 일기** — 일/주/월 단위 라이딩 기록 시각화
- 📊 **통계 & 시각화** — 최고 속도, 누적 고도, 라이딩 패턴 등 한눈에 확인

## ⚙️ 기술 문서

### 1️⃣ 라이딩 기록

**목적:** 라이딩을 하면서 현재 위치한 고도와 속도를 측정

**데이터 출처:** 고도(altitude), 속도(speed), 심박수(heartRate)

**로직:**
- Apple Watch에서 라이딩 시작 버튼을 누르고 라이딩 진행
- 라이딩 도중 **30초 이상 속도가 10km/h 미만**일 경우 알림을 띄워 일시정지 여부 선택 가능
- 세션 종료 시 Watch → iPhone으로 WatchConnectivity를 통해 데이터 자동 전송

**슬로프 레벨 자동 판정 (고도 상승량 기준):**
| 레벨 | 기준 | 이모지 |
|------|------|--------|
| 초급 | 고도 상승 200m 미만 | 🟢 |
| 중급 | 200m 이상 400m 미만 | 🔵 |
| 상급 | 400m 이상 600m 미만 | ⚫️ |
| 최상급 | 600m 이상 | 💎 |

**🏔️ 오늘의 라이딩 (예시)**
- 최고 속도: 45.2 km/h
- 평균 속도: 28.5 km/h
- 고도 상승: 850m (최상급 슬로프)
- 라이딩 시간: 3시간 25분
- 평균 심박수: 142 bpm

**사용 기술:**
- `CoreLocation` — GPS, 고도, 속도
- `HealthKit` — 심박수, 워크아웃 세션 (`HKWorkoutSession`)
- `WatchConnectivity` — Watch ↔ iPhone 데이터 동기화
- `SwiftData` + `App Groups` — 로컬 데이터 저장 및 공유 컨테이너
- `SwiftUI` + `Combine` — 실시간 데이터 바인딩

---

### 2️⃣ 캘린더

**목적:** 나의 라이딩을 캘린더에 하루하루 기록함으로써 추억 + 동기부여

**로직:**
- 오늘의 라이딩을 기록한 후 **오늘의 라이딩 한줄평** (50자 이내) 작성 가능
- **사진 1장** 첨부 가능 — 갤러리에서 선택 (`PhotosUI`)
- 라이딩 기록이 있는 날짜는 캘린더에 컬러 인디케이터로 표시
  - 🔵 파란 점: 라이딩 기록 있음
  - 🟠 주황 점: 라이딩 기록 + 일기 작성 완료

**표시 데이터:** 최고 고도, 평균 속도, 총 라이딩 시간, 고도 상승량

**구현 포인트:**
- `SwiftData` — 로컬 데이터 저장
- SwiftUI 커스텀 `CalendarView` 구현
- `PhotosUI` — 갤러리에서 사진 선택
